## Pipeline

`load → explore → clean → select features → StandardScaler → choose K (elbow + silhouette)
→ K-Means → visualise → profile clusters → generate personas`

## Files

| File | Contents |
| --- | --- |
| `customer_persona_generation.py` | The full pipeline. Regenerates the dataset if it is missing, so the run is reproducible. |
| `customer_marketing_data.csv` | Input dataset, 216 records with demographic, geographic and behavioural attributes. |
| `customers_with_clusters.csv` | Cleaned dataset with the assigned cluster label per customer. |
| `generated_personas.csv` | The five personas produced, one row each. |
| `figures/fig_elbow.png` | Elbow method and silhouette score against K. |
| `figures/fig_clusters.png` | Cluster scatter plots with centroids. |
| `figures/fig_profiles.png` | Cluster profile comparison across all five features. |

## Result

K = 5 was selected on the agreement of the elbow method and the highest mean silhouette
score (0.490). The five segments are:

| Cluster | Persona | Share | Income (k INR) | Spending score |
| --- | --- | --- | --- | --- |
| 0 | Young Budget Minimalist | 22.2 % | 358 | 28 |
| 1 | Young Impulsive Explorer | 21.7 % | 439 | 77 |
| 2 | Senior Cautious Affluent | 16.0 % | 1584 | 19 |
| 3 | Mid-career Premium Loyalist | 17.0 % | 1450 | 81 |
| 4 | Mid-career Steady Mainstream | 23.1 % | 879 | 50 |

Income and spending score do not move together — cluster 2 has the highest income in the
dataset but the lowest spending score. Segmenting on income alone would have merged two
opposite groups and produced the wrong campaign for both.

## Note on the dataset

The dataset is generated by the script rather than downloaded, so the experiment is fully
reproducible from the code alone. It is built to contain five latent buying behaviours, with
duplicate rows and missing values deliberately injected so that the cleaning step does real
work rather than being a formality.
